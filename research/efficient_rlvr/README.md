# Efficient RLVR research branch

This directory starts an additive research line on reducing RLVR inference cost while retaining verified answer accuracy. The Phase A–C archive is the immutable reference point; this branch does not alter its predictions, scores, splits, or candidate choices.

Phase 1 found longer selected-adapter outputs and higher aggregate inference cost in both frozen Phase C pairs. Those decoded-text token counts are reconstructed, because per-question token IDs were not saved. They are post-hoc descriptions only and do not change archived accuracy or model selection.

[`artifact_manifest.json`](artifact_manifest.json) records SHA-256 and size for code, reports, the local locked data, and the local smoke checkpoint. It identifies ignored/private-to-workspace artifacts separately from files intended for Git.

The Phase 2 smoke verifies code-path correctness, not model quality. It used one optimizer update on local RTX 3060 and produced nonzero gradient/reward variance, changed LoRA parameters, token accounting, and a checkpoint that reloaded exactly. Five failed engineering attempts are retained in the attempt history.

The Phase 3 data are generated by the pinned DeepMind Mathematics Dataset source. The upstream code is Apache-2.0, but its repository does not separately state a license for generated outputs; to avoid implying otherwise, the JSONL rows remain local and ignored by Git. Anyone can regenerate the same hashes from the pinned source and seeds. Text-level overlap checks covered 730 JSON/JSONL/Parquet files across archived data, reports, and saved run traces (60,533 prompt-text entries), with no exact or punctuation-insensitive match. This does not prove no pretraining exposure.

## Offline validation

From WSL/Linux at the repository root, create the generator/test environment and run both suites:

```bash
python3.12 -m venv .venv-data
source .venv-data/bin/activate
python -m pip install -r research/efficient_rlvr/requirements-data.lock.txt
python -m unittest discover -s research/efficient_rlvr/tests -v
python -m unittest discover -s tests -v
python -m compileall -q research/efficient_rlvr agent_rl scripts tests
```

Run the actual JSON/JSONL/Parquet history scan in a separate environment using `requirements-audit.lock.txt`; PyArrow 26 needs NumPy 2+, while the data generator is pinned to NumPy 1.26.4 because it uses NumPy RNG. Rebuild and audit commands, including the upstream source revision, are in the [dataset README](../../data/efficient-rlvr-math-v1/README.md). The local RTX 3060 implementation smoke command and all failed attempts are documented in [Phase 2 design](phase2_design.md) and [smoke history](phase2_smoke_history.md).

## Research guardrails

- Consumed GSM8K and SVAMP tests are descriptive history only; they cannot select any method in this branch.
- The locked extrapolation test is sealed from checkpoint, reward, group-filter, stop, and prompt choices.
- GRPO-LEAD, GFPO, DAPO, and Dr. GRPO are prior work. CGLR and correctness-mixed group filtering are baselines, not novelty claims.
- Compare attempted generated tokens including discarded rollouts, wall-clock and billed GPU time, exact accuracy, parse failures, latency, and correct solutions per GPU-hour.
- Report training-seed variation separately from paired question-level uncertainty. Mixed or negative results are valid outcomes.
- Do not start paid compute until the user explicitly approves the concrete AutoDL budget and cap.
