# SVAMP external test set

Source: [`arkilpatel/SVAMP`](https://github.com/arkilpatel/SVAMP), repository commit `78e727689e1c1bebfc4be39c446898e8e10b0518`. The full 1,000-row challenge set is stored as `test.jsonl`; the conversion recipe is `scripts/prepare_svamp.py`, and `manifest.json` records both source and output SHA-256 hashes. The MIT license and copyright notice from the pinned source are included here in `LICENSE` and with the upstream source in `../svamp-source/LICENSE`.

This full set was used once for the Phase C seed 2 Base/selected-Group4 paired evaluation. It is consumed for this experiment and must not be reused for checkpoint selection or tuning.
